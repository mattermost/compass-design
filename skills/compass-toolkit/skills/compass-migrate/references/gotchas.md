# Gotchas, by compass-ui version

Each row says where it comes from and which versions it applies to. **Verified** means I checked it against the compass-ui source at alpha.30 (which differs from alpha.29 only in `ModalOverlay`'s `zIndex` type, the `--z-confirm-modal` token and the icons peer), or against the release commit named in the row. **Seen** means a reference migration did it (gcal = mattermost-plugin-google-calendar PR 179, alpha.22; agents = mattermost-plugin-agents, alpha.23). **Reported** means consumer feedback that I could not reproduce here: treat it as a lead, confirm it, and don't state it to the user as fact.

Before relying on any row, read the installed compass-ui version and the `CHANGELOG.md` entry for the release that matches. If a row's fix has shipped, follow the new behavior and drop the workaround.

## When a gotcha isn't listed

Check the `CHANGELOG.md` for the installed version and the one after it. If the behavior you hit looks like a Compass defect, report it in section 4 of the report rather than working around it silently.
