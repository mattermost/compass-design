# Old component to Compass component

Use this in step 1 (inventory). Rows marked **seen** were migrated this way in a reference migration: `gcal` is mattermost-plugin-google-calendar PR 179 (compass-ui alpha.22) and `agents` is mattermost-plugin-agents (alpha.23). Rows marked **source** come from the compass-ui source at alpha.30. Anything not in this table: check `../../compass-build/references/components.md`, and if nothing fits, `not-covered.md`.

Import rule: subpath imports only, for example `@mattermost/compass-ui/components/combobox`. Never the root barrel. Icons come from `@mattermost/compass-icons/components`.

| Old                                                            | Compass                                                                                                 | Notes                                                                                                                                                                                          |
| -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| react-bootstrap `Modal` (+ `Modal.Header`, `.Body`, `.Footer`) | `ModalOverlay` + `Modal`                                                                                | **seen** (gcal). Header, body and footer become the `title` prop, children and the `footer` prop. The overlay owns the scrim, portal and scroll lock; the host owns `open`.                    |
| Custom confirm or "are you sure" modal                         | `ModalOverlay` + `Modal` with two `Button`s in `footer`                                                 | **source**. Compass has no confirm component, and older hand-rolled versions build their own overlay. See the confirm pattern.                                                                 |
| react-bootstrap `Button`, or a custom `FormButton`             | `Button`                                                                                                | **seen** (gcal). `emphasis` (`primary`, `secondary`, `tertiary`), `loading`, `disabled`, `destructive`, `type`, and `form` to submit a form from a modal footer. One `primary` per view.       |
| A `Setting` wrapper (label, help text, input)                  | The input's own props                                                                                   | **seen** (gcal). `label` takes a `ReactNode`; Select and Combobox also take `message` and `messageTone`. Delete the wrapper.                                                                   |
| Text `<input>`                                                 | `TextInput`                                                                                             | **seen** (gcal). `label`, `required`, `value`, `onChange`.                                                                                                                                     |
| `<textarea>`                                                   | `TextArea`                                                                                              | **seen** (gcal).                                                                                                                                                                               |
| react-select `Select` (sync)                                   | `Select`                                                                                                | **seen** (gcal `TimeSelector`). Takes `options` as `{label, value}`.                                                                                                                           |

Recipe in `patterns.md`.                                                                                                                                                      |
| react-select `Creatable`, `AsyncCreatable`                     | `Combobox` with `creatable` and `onCreateOption`                                                        | **seen** (gcal attendees).                                                                                                                                                                     |
| react-select multi                                             | `Combobox` with `multiple`                                                                              | **seen** (gcal). Use its own `label` prop from alpha.28; older versions do not have it, so keep a separate `<label htmlFor>` (as gcal did at alpha.22) or upgrade. |

| Icon-only button                                               | `IconButton` with `icon={<Icon glyph={...}/>}` and an `aria-label`                                      | **seen** (gcal header, agents). Omit `size`; the button sizes the icon.                                                                                                                        |
| Field error under an input                                     | The input's own `message` prop (error tone by default) on `TextInput`, `TextArea`, `Select`, `Combobox` | **source**. gcal drew a separate `ErrorMessage`, which is `FieldMessage` in the error tone kept for existing imports; use it only where the input has no `message` (`DateRangePicker`).        |
| Request-level error, warning or info banner                    | `SectionNotice`                                                                                         | **seen** (gcal: `type='danger'`, `role='alert'`). Types: `info`, `warning`, `danger`, `success`, `hint`.                                                                                       |
| Empty list or panel                                            | `EmptyState`                                                                                            | **seen** (gcal, agents). The action `Button` omits `size`.                                                                                                                                     |
| Status or category labels; removable or filter chips           | `Tag` for labels (a role, tier, status or category), `Chip` for removable chips                         | **seen** (agents, for `Tag`); `Chip` is from the compass-ui source. | Avatars                                                        | `UserAvatar`, `UserAvatarGroup`, `TeamAvatar`                                                           | **seen** (agents). | Search box                                                     | `SearchInput`                                                                                           | **seen** (agents).                                                                                                                                                                             |
| Tabs                                                           | `Tabs`                                                                                                  | **seen** (agents).                                                                                                                                                                             |
