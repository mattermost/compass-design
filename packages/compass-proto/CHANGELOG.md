# Changelog

All notable changes to `@mattermost/compass-proto` are documented here.

`compass-proto` is unpublished (`private: true`) prototyping UI, so there are no releases or version sections: entries stay under `[Unreleased]`, each prefixed with the date it landed on `main` (`YYYY-MM-DD`, newest first). Changes to the published `@mattermost/compass-ui` package belong in [its changelog](../compass-ui/CHANGELOG.md), not here.

Format follows [Keep a Changelog](https://keepachangelog.com/).

## [Unreleased]

### Added

- **2026-11-15 · Product Rail unread dots use `UnreadBadge`; team menu rows use `MenuItem`:** the dots on rail tiles and the team button, and the unread dot in the team menu, are now compass `UnreadBadge`s (decorative where the control's accessible name already carries the status; labelled via `unreadLabel` in the menu). Team menu rows moved from custom buttons to `MenuItem` (`role="menuitemradio"`, `aria-checked`); the unread dot is centred in a check-sized box so it lines up with the check. `ProductRailTeam.urgent` is removed because `MenuItem`'s mention count has no urgent style. Part of #273.
- **2026-11-15 · `ProductRailTeamMenu` keyboard support and `onClose`:** with `open` controlled, focus moves into the menu on the current team; Arrow Up/Down (wrapping), Home and End move between rows; Escape calls the new optional `onClose` (skipped if an inner handler already prevented it) so the host can close the menu and return focus to the trigger. The team button now uses the shared focus ring. Part of #273.
- **2026-11-15 · `ClipboardTextOutlineIcon`, `BullseyeArrowIcon`, `MessageProcessingOutlineIcon` and `BookOpenVariantOutlineIcon`:** local icons for Playbooks, Boards, Channels and Docs (Boards and Playbooks use the adjusted lighter drawings from design) (the Channels one is a speech bubble with three round dots), since `@mattermost/compass-icons` does not ship them. Same API as compass-icons components (`size`, `color`, SVG pass-through). Used by the Product Rail demos (all four) and by `ProductSwitcherMenu`'s Channels, Boards and Playbooks rows (replacing the compass-icons `product-channels` / `product-boards` / `product-playbooks` glyphs there). `GlobalHeader`'s product branding uses them too (Channels, Boards, Playbooks, plus Docs with the open-book icon), so the header, rail and switcher menu match. Part of #273.
- **2026-11-14 · Product Rail accessibility and label hooks:** `ProductRail` now forwards `mentionsLabel` and `unreadLabel` to every item; a rich-node item `label` keeps its unread/mention status for assistive tech; `ProductRailTeamButton` names the current team (and, via `otherTeamsUnreadLabel`, other teams' unread activity); team menu rows are `menuitemradio` with `aria-checked` and speak unread (`unreadLabel`). Part of #273.
- **2026-11-14 · `ProductRailTeamButton` and `ProductRailTeamMenu`:** team switcher for the top of the `ProductRail` (via its `header` slot), standing in for the Team Sidebar: current team on peeking cards with an other-teams-unread dot, and a team menu with current check, mention counts, unread dots, and an optional "Show team sidebar" row. The button uses Team Avatar with the webapp's background and hover customizations (a sidebar-tinted fill behind initials, a shadow, and a header-colour ring and shadow lift on hover instead of Team Avatar's hover outline); the menu rows are compass `MenuItem`s (Team Avatar menu variant leading, default check for the current team, inline mention count, `UnreadBadge` for unread teams). `ProductRailTeamMenu` takes `open` / `onExited` for the Compass popover transition (scale + fade, reduced-motion aware); the host owns open state and positioning. Used by the Product layout. Part of #273.
- **2026-11-14 · `ProductShell`:** product-agnostic desktop layout with the `ProductRail` in place of the Team Sidebar (`productRail`, optional `sidebar`, `children`, `trailing`, `floating`, `overlay`, `globalHeaderProps`). Shares its frame styles with `ChannelShell`, which is unchanged. Part of #273.
- **2026-11-13 · `ChannelBookmarksBar` and `ChannelBookmarkModal`:** channel bookmarks bar for under the channel header. Bookmarks can carry an emoji; those that don't fit collapse into a `+N` overflow chip; each bookmark has an actions menu (edit, copy link, delete); an inline plus button opens an add menu (link or attachment) and `ChannelBookmarkModal` renders the matching form (link or file, plus an emoji picker). With no bookmarks the plus button becomes an "Add bookmark" chip. Controlled by the host through callbacks (`onAdd(type)`); strings are overridable via `labels`. Shown in the Channel layout specimen and the Channel Bookmarks Bar docs topic.
- **2026-11-13 · `ProductRail` and `ProductRailItem`:** labeled vertical product rail styled after the Mattermost webapp rail (72px, icon chip with selected tint, label beneath, mention/unread badges incl. `urgent`, `header`/`footer` slots, translatable `navLabel`, `mentionsLabel`, `unreadLabel`). Not yet slotted into `ChannelShell` (tracked in #360). Documented under Patterns. Part of #273. Also adds a `vitest` setup (`npm test`) to this package.
- **2026-11-13 · `QuickSwitchModal`:** keyboard-first "Find channels" switcher (Ctrl/Cmd+K dialog) matching the Patterns — Modals Figma: titled `Modal` (with a keyboard-help subtitle) with a `SearchInput` in the header, grouped `MenuItem` rows (`MenuGroupHeading` for Unread / Recent) with an inline `~handle`. Takes `items` and `onSelect` (plus `open`, `onClose`, optional `filter`, `onQueryChange`, `overlayProps`, and label props with English defaults); also exports `filterQuickSwitchItems` and the `QuickSwitchItem` type. Groups show only while the query is empty; typing flattens them into one list ranked by match closeness. A leading `~` in the query limits results to channels and `@` to direct messages (`QuickSwitchItem.kind`, inferred from an `@handle` when unset; `quickSwitchScope` / `quickSwitchKind` exported). Part of #263.

### Changed

- **2026-11-15 · Product Rail mention badge position:** the mention badge is positioned by its centre (so it stays put whatever its width), 2px down and 2px left of the unread dot's centre at the top-right of the icon chip. Part of #273.
- **2026-11-15 · `GlobalHeader` `showProductBranding`; `ProductShell` hides the header product name:** new `showProductBranding` prop (default `true`, so existing uses are unchanged) hides the product icon and name for any product. `ProductShell` sets it to `false` because the Product Rail already shows the active product; pass `globalHeaderProps={{ showProductBranding: true }}` to restore it. Part of #273.
- **2026-11-14 · `GlobalHeader` `product` accepts `'agents'`, `'docs'`, `'automation'`:** adds branding (sparkle `creation-outline`, `book-outline`, `lightning-bolt-outline` icons) for the new Product Rail products. Existing values are unchanged. Part of #273.
- **2026-11-12 · `MobileMessageInput` `variant` values are now lowercase kebab-case (breaking for hosts that passed the old values):** `variant` takes `'root'` and `'reply'` instead of `'Root'` and `'Reply'`, matching the public variant-value convention. Update any `variant="Root"` / `variant="Reply"` usage to the lowercase values; the default is still `'root'`. Nothing else in the component's API changes.
