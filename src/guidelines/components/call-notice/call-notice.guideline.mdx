import { CallNotice } from '@mattermost/compass-proto';

`CallNotice` lives in `@mattermost/compass-proto` (call prototyping), alongside `RecordingIndicator`.

Call Notices surface lightweight, transient signals during a call —
emoji reactions, raised hands, and system notifications like "you've been
muted." They float over the call surface long enough to register and then
disappear; they aren't meant to be durable UI.

Reach for a Call Notice when something happens during a call that the
participant should notice without leaving their current view.

<Divider />

## Anatomy

Pills compose a leading symbol with a label, and — for system notifications —
a trailing icon.

<AnatomyStage
  style={{ flexDirection: 'column', gap: '0.75rem', alignItems: 'flex-start' }}
>
  <CallNotice type="reaction" emoji="🎉" label="Leonard R." />
  <CallNotice type="hand-raise" label="Leonard R." />
  <CallNotice type="other" message="You have been muted by the host" />
</AnatomyStage>

- <Num>1</Num> **Leading symbol** — an emoji (Reaction) or compass icon (Hand
  Raise, Other).
- <Num>2</Num> **Label** — the participant's name, the reaction text, or the
  system message.
- <Num>3</Num> **Trailing icon** — only on the Other (system) variant. It is
  decorative; the notice is not dismissible.

<Divider />

## Variants

| Variant    | Use when                                                                          |
| ---------- | --------------------------------------------------------------------------------- |
| Reaction   | A participant sends an emoji reaction. Show the emoji + their name.               |
| Hand Raise | A participant raises their hand. Show the hand icon + "[Name] Raised Hand".       |
| Other      | A system notification (muted, removed, etc.). Show the system icon + the message. |

<Divider />

## Appearance

The `appearance` prop picks the surface the notice sits on.

| Appearance       | Use when                                                                                            |
| ---------------- | --------------------------------------------------------------------------------------------------- |
| `default`        | The notice floats over a dark call surface — the stage, popout, or mobile call screen. Dark indigo. |
| `center-channel` | The notice sits over a light surface, such as the call widget. Light fill, border, and dark text.   |

`center-channel` works with every type and size. Reaction and Other use the
center-channel colors; Hand Raise keeps its indigo identity with
indigo text and icon.

## Tone

System notices (`type="other"`) take a `tone` for severity, mirroring the
`warning` and `error` alerts in the Calls plugin.

| Tone      | Use when                                                                               |
| --------- | -------------------------------------------------------------------------------------- |
| `default` | Neutral information: muted by the host, host changed, link copied.                     |
| `warning` | Something may degrade the call but it still works: unstable network, device fell back. |
| `error`   | Something is blocked and needs action: no microphone or camera, permission denied.     |

Warning (mustard with light text, matching the Toast) and error (red with light text) are solid fills
that read the same on dark and light surfaces, so `appearance` does not change
them.
Reactions and raised hands are participant signals, not alerts, and ignore
`tone`. Pass `icon` to match the cause (for example a camera-off icon for a
missing camera); otherwise warning shows an alert icon and error an
alert-circle icon.

<div
  style={{
    display: 'flex',
    gap: '1rem',
    flexWrap: 'wrap',
    alignItems: 'center',
    padding: '1rem 0',
  }}
>
  <CallNotice
    type="other"
    tone="warning"
    message="Call quality may be degraded due to unstable network conditions."
  />
  <CallNotice
    type="other"
    tone="error"
    message="Allow microphone access to Mattermost."
  />
</div>

Three sizes match the call surface — **Small** for compact in-call rails,
**Medium** for the main stage overlay, **Large** for full-screen mobile.

## When to use

A Call Notice looks a lot like a toast, but it is a different tool.

| Call Notice                                                         | Toast                                      |
| ------------------------------------------------------------------- | ------------------------------------------ |
| Floats over the call surface and belongs to the call's context.     | App-level, independent of any one surface. |
| Carries signals from participants, like reactions and raised hands. | Reports the result of something you did.   |

Use a Call Notice for anything that happens inside a call. Use a toast for
app-level feedback outside it.

## Implementation

For props, variants, and copy-ready examples, see the
[Call Notice specimen page](/components/call-notice/specimen).

```tsx
// Over the call widget (light surface)
<CallNotice appearance="center-channel" type="other" message="Call link copied" />

// A blocking problem, with a matching icon
<CallNotice
  type="other"
  tone="error"
  icon={<VideoOffOutlineIcon />}
  message="Allow camera access to Mattermost."
/>
```
