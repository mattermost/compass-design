import { ErrorMessage } from '@mattermost/compass-ui/components/error-message';

Error Message is the inline red error line under a form field. It is
`FieldMessage` with `tone="error"` — kept so existing imports (e.g. Agents
plugin) stay valid.

For warning, info, or success, use [`FieldMessage`](/components/field-message).
Under a text field, prefer the field's `message` / `messageTone` props.
