Field Message is the inline status line under a form field — validation
errors, warnings, hints, or success. It pairs a tone glyph with a short
explanation so the user knows what to do next.

**Under a text field,** pass `message` / `messageTone` on
[Text Input](/components/text-input), [Text Area](/components/text-area), or
[Search Input](/components/search-input) so the field owns `aria-describedby`
and invalid chrome.

**Standalone,** use Field Message when the line sits under something else
(for example a radio group).
[`ErrorMessage`](/components/error-message) is the same component locked to
`tone="error"` for existing callers.

    tone="info"
    message="Use 8 or more characters with a mix of letters and numbers."
  />
  <FieldMessage tone="success" message="Invite link copied." />
</AnatomyStage>

- <Num>1</Num> **Icon** — tone glyph at 12px. Decorative; meaning is carried by
  the text.
- <Num>2</Num> **Message** — one sentence, plain language.

Error and warning use `role="alert"`. Info and success do not.
