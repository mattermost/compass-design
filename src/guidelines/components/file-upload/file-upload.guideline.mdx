File Upload lets people choose files from their device for an import, an icon
or logo, or an attachment on a form. It comes as a dashed drop zone or a plain
picker button, and it works fully from the keyboard.

File Upload only reports the files people select. Sending them, showing
progress, and listing what was chosen stay with the screen that uses it. For a
chosen-file row, reach for [Attachment Card](/components/attachment-card).

- <Num>1</Num> **Icon** — an upload glyph, or a spinner while `loading`.
- <Num>2</Num> **Label** — what the zone is for. Swaps to the drag label while
  files are dragged over it.
- <Num>3</Num> **Browse text** — opens the file dialog. This is also the
  accessible name of the file input.
- <Num>4</Num> **Description** — optional hint for accepted types and limits.
- <Num>5</Num> **Field message** — optional validation or status line below.

## Variants

The drop zone suits a screen where the file is the main task. The button suits
a form row or toolbar where space is tight; it does not accept drops.

## Validation

Pass `accept`, `maxSize` (bytes) and `maxFiles`. Dropped files are checked
against `accept` too, which the native attribute does not do. Files that fail
are not passed to `onFilesSelected`; they arrive in `onFilesRejected` with a
reason of `file-type`, `file-size` or `too-many-files`. Turn those into your own
translated `message`. Single-file mode (the default) accepts one file per
selection.

<Divider />

## Keyboard and screen readers

Tab focuses the zone; Enter or Space opens the file dialog. The picker never
depends on drag and drop. The description and message are linked to the
input automatically, and an error-tone `message` marks the input invalid.
