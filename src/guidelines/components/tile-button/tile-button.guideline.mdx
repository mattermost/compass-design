Tile Buttons surface a small set of high-frequency actions in a fixed
context — a profile popover, a channel info panel, a card. They sit close to
the content they act on and read as a row of equal-weight choices.

Reach for a Tile Button when an icon plus a one-word label communicates
faster than a labelled Button, and when several related actions need to sit
side-by-side without one outranking the others.

<Divider />

## Anatomy

Three parts — container, icon, and label — stacked vertically.

- <Num>1</Num> **Container** — the surface that gives the action its shape and
  hit target.
- <Num>2</Num> **Icon** — required. Reinforces the action at a glance.
- <Num>3</Num> **Label** — required. Action verb, four words or fewer. A long
  label wraps to a second line, centred and balanced, then is cut off with an
  ellipsis; the icon stays at the top so icons line up across a row.

## States

Tile Buttons have three interactive states — Default, Hover, and Toggled —
plus a Destructive variant. The Toggled state signals that the action is
toggled on (e.g. "Following").

<SampleRow>
  <TileButton
    icon={<Icon glyph={<MessageTextOutlineIcon />} />}
    label="Default"
  />
  <TileButton
    icon={<Icon glyph={<AccountPlusOutlineIcon />} />}
    label="Toggled"
    toggled
  />
  <TileButton
    icon={<Icon glyph={<MessageTextOutlineIcon />} />}
    label="Disabled"
    disabled
  />
</SampleRow>

## Destructive

Use the destructive variant only for actions that remove or undo something —
leaving a channel, removing a member from a group DM, deleting a saved item.
Pair it with a confirmation step; the button itself isn't a confirmation.

<SampleRow>
  <TileButton
    icon={<Icon glyph={<TrashCanOutlineIcon />} />}
    label="Remove"
    destructive
  />
</SampleRow>

## When to use

- **Tile Button that renders a link** — a fixed-context navigation choice,
  such as "View profile" in a profile popover. Pass `asChild` with an empty
  `<a>` or router `Link` child. Toggle state (`toggled` / `aria-pressed`) is
  not available on links — use a plain Tile Button for on/off controls.
- **Plain Tile Button** — actions in that same fixed context that change
  state (mute, favorite) without navigating.

<Divider />

## Implementation

Pass `asChild` with a single empty `<a>` or router `Link` child to render a
navigational action:

```tsx
import { TileButton } from '@mattermost/compass-ui/components/tile-button';
import { Icon } from '@mattermost/compass-ui/components/icon';
import AccountOutlineIcon from '@mattermost/compass-icons/components/account-outline';
import { Link } from 'react-router-dom';

<TileButton
  asChild
  icon={<Icon glyph={<AccountOutlineIcon />} />}
  label="View profile"
>
  <Link to="/users/me" />
</TileButton>;
```
