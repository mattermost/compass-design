The Thread Footer is the reply summary bar at the bottom of a message. It
shows participants, reply count, follow state, and last-reply time — the
information someone needs to decide whether to dive in.

## Anatomy

- <Num>1</Num> **Avatars** — a User Avatar Group of up to three participants,
  plus a `+N` overflow when more than three users have replied.
- <Num>2</Num> **Reply count** — quaternary button labelled "N replies"; this
  is the primary entry point into the thread.
- <Num>3</Num> **Follow toggle** — quaternary button that toggles between
  "Follow" and "Following".
- <Num>4</Num> **Last reply time** — relative timestamp ("5m ago"), revealed on
  row hover or keyboard focus when the user is following the thread.
- <Num>5</Num> **Badge slot** — optional unread dot or [Mention Badge](/components/mention-badge)
  to the left of the avatar stack.

## Variants

| Variant     | Use when                                                                          |
| ----------- | --------------------------------------------------------------------------------- |
| Default     | The user hasn't followed this thread and has no unread state on it.               |
| Following   | The user is following the thread; last reply time appears on row hover.         |
| Unread      | The user is following and has unread replies; show the unread dot badge.         |
| Mention     | The user has unread `@`mentions in the thread; show a Mention Badge count.            |

## Behavior

- The reply count is the primary action — clicking it opens the thread in
  the right sidebar.
- Follow / Following is a self-contained toggle. Following adds the thread to
  the user's Threads view; last-reply time appears when the pointer or keyboard
  focus is anywhere on the footer row. Dividers are hidden while Following is
  active.
- The unread dot appears when the user is following **and** there are unread
  replies. It clears once the user has read everything in the thread.
- Mention badge wins over unread dot — if the user is mentioned, surface the
  mention regardless of read state.
- Unread and mention badges are decorative (`aria-hidden`). Screen readers get
  state from a visually hidden status hint in the avatar group (`Unread replies` or
  `` `${count} mention(s)` ``).

<Divider />

## Accessibility

- Reply and Follow buttons expose their own labels; badge glyphs do not duplicate
  that copy.
- Hosts may set `--thread-footer-focus-ring-color` (or `--focus-ring-color`) on the root to align focus
  rings on Reply/Follow; both default to the theme focus ring.

- Reply count uses the singular when there's exactly one reply ("1 reply",
  not "1 replies").
- Last-reply time is relative and short ("just now", "5m ago", "2d ago"),
  not a full date.
