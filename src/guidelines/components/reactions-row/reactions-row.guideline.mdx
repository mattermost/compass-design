Reactions Row is the strip of [Reaction Buttons](/components/reaction-button) below a message —
the lightest weight way to respond, applaud, or acknowledge without adding to the thread.
The component handles layout, the add-reaction affordance, and the optional Acknowledge button.

<Divider />

## Anatomy

A horizontal flex row. Each [Reaction Button](/components/reaction-button) carries one emoji and
the count of users who picked it; the row may also include an Acknowledge button and an
add-reaction control.

- <Num>1</Num> **Reaction Button** — emoji + count. Click to toggle your own reaction. See
  [Reaction Button](/components/reaction-button) for states and accessibility details.
- <Num>2</Num> **Acknowledge** — optional button with a check glyph. When the current user has
  acknowledged, it shows a count instead of the word.
- <Num>3</Num> **Add reaction** — optional `+` Icon Button that opens the Emoji Popover.

<AnatomyStage>

    reactions={[
      { emoji: '👍', count: 3, byCurrentUser: true },
      { emoji: '😀', count: 4 },
      { emoji: '🙌', count: 1 },
    ]}
    showAddReaction
  />
</AnatomyStage>

## Reaction Button states

Each [Reaction Button](/components/reaction-button) has two visual variants plus the standard
interactive states.

| State              | Use when                                                                |
| ------------------ | ----------------------------------------------------------------------- |
| Default            | At least one other user reacted with this emoji; you haven't.           |
| Mine               | The current user has reacted. Button takes a brand-colour outline + soft fill. |

When a Reaction Button is clicked, animate the count up by one with a quick increment;
when removed, animate down. The animation is instant feedback before the
server confirms.

## Acknowledge

Acknowledge is a higher-emphasis "I saw this" with a different visual
treatment — a check glyph, the word "Acknowledge" until the current user
opts in, and a count once they have.

<div style={{display:'flex',flexDirection:'column',gap:'0.75rem',padding:'1rem',background:'var(--center-channel-bg)',border:'1px solid rgba(var(--center-channel-color-rgb),0.08)',borderRadius:'8px'}}>
  <ReactionsRow
    acknowledged
    acknowledgeCount={0}
    reactions={[]}
  />
  <ReactionsRow
    acknowledged
    acknowledgeCount={4}
    currentUserAcknowledged
    reactions={[
      { emoji: '👍', count: 2 },
    ]}
  />
</div>

Use Acknowledge sparingly — it's reserved for messages where confirmation
matters (announcements, policy updates). Don't enable it on every channel by
default.
