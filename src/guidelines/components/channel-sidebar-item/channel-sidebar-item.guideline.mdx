The Channel Sidebar Item is the row people use to move between channels,
DMs, and group messages. It compresses a lot of state — channel type,
unread, mention count, mute, in-call — into a single, scannable line.

Use it inside the Channel Sidebar pattern. For freeform navigation lists,
reach for Menu Items instead.

<Divider />

## Anatomy

- <Num>1</Num> **Leading visual** — the icon or avatar that identifies the
  channel type. Public, Private, Group Message, Direct Message, and special
  rows like Threads, Drafts, and Insights each have their own glyph.
- <Num>2</Num> **Label** — the channel, group, or user name.
- <Num>3</Num> **Active border** — a 3px left-edge accent shown on the
  currently selected item.
- <Num>4</Num> **Mention badge** — numeric badge shown when the row has
  unread mentions.
- <Num>5</Num> **Channel menu** — three-dot button revealed on hover for
  channel and DM rows.
- <Num>6</Num> **Trailing decorations** — call-in-progress glyph, custom
  status emoji on DMs, shared-channel marker.

## Leading visuals

| Visual         | Use for                                                   |
| -------------- | --------------------------------------------------------- |
| Public         | Public channels in the team.                              |
| Private        | Private channels.                                         |
| Group Message  | Multi-person DMs. Member count appears in the glyph.      |
| Direct Message | One-on-one DMs. The user's avatar is the visual.          |
| Threads        | The Threads inbox row.                                    |
| Drafts         | The Drafts row.                                           |
| Insights       | The Insights row.                                         |

## Status

The row's status drives weight, color, and trailing badge.

| Status  | Treatment                                                            |
| ------- | -------------------------------------------------------------------- |
| Read    | Resting weight; the row recedes.                                     |
| Unread  | Semibold name; brighter text color.                                  |
| Mention | Semibold name; mention badge with count.                             |

Mute reduces opacity across the row regardless of status — muted channels
shouldn't compete for attention even when they have unreads.

<Divider />

## Active and hover

A single item is **Active** at any time — it shows the left-edge border, an
elevated background, and stays in that state until the user navigates away.
On hover, non-active rows show a subtle background. The channel menu (three
dots) appears on hover or keyboard focus within the row (`:focus-within`) so
Tab users can reach the menu without pointer hover. The menu stays in the tab
order via opacity (not `display: none`); the mention badge fades out while the
menu is visible.

Unread and mention state is announced to screen readers via a visually hidden
status hint on the channel button (`unread` or
`` `${count} mention${count === 1 ? "" : "s"}` ``); the mention count pill is
decorative only (`aria-hidden`).
