import { Icon } from '@mattermost/compass-ui/components/icon';
import GlobeIcon from '@mattermost/compass-icons/components/globe';
import StarOutlineIcon from '@mattermost/compass-icons/components/star-outline';
import TrashCanOutlineIcon from '@mattermost/compass-icons/components/trash-can-outline';
import CloseIcon from '@mattermost/compass-icons/components/close';

Icon Buttons are compact, label-free actions for tight surfaces — channel
headers, message hover actions, modal dismissals, toolbar slots. They lean
on the icon to communicate intent, so every Icon Button must pair with a
tooltip or `aria-label` that makes the action explicit.

<Divider />

## Anatomy

A square (or pill) target wrapping a single Icon. Optional add-ons attach a
count or an unread dot.

<AnatomyStage style={{ gap: '1rem' }}>
  <IconButton aria-label="Globe" icon={<Icon glyph={<GlobeIcon />} />} />
  <IconButton
    aria-label="Notifications"
    count={12}
    icon={<Icon glyph={<GlobeIcon />} />}
  />
  <IconButton
    aria-label="Unread"
    unreadBadge
    icon={<Icon glyph={<GlobeIcon />} />}
  />
</AnatomyStage>

- <Num>1</Num> **Container** — square or pill (rounded) target. Sized to the
  chosen size token; defaults to 4px corner radius.
- <Num>2</Num> **Icon** — pass `<Icon glyph={<SomeIcon />} />` with no `size`;
  Icon Button injects the matching size via context.
- <Num>3</Num> **Count** — optional inline number after the icon. Replaces the
  fixed-square layout with an auto-width row.
- <Num>4</Num> **Unread badge** — optional small dot top-right. Use when a count
  would be noise but the user should know there's something to see.

available where the surrounding rhythm calls for a tighter target — table

## States

Icon Buttons share the standard interactive states — Default, Hover, Focus,
Active, Disabled — and add **Toggled** for on/off controls and **Loading**
for async actions.

<div
  style={{
    display: 'flex',
    alignItems: 'center',
    gap: '0.75rem',
    padding: '1.5rem',
    background: 'rgba(0,0,0,0.04)',
    borderRadius: '8px',
  }}
>
  <IconButton
    aria-label="Default"
    icon={<Icon glyph={<StarOutlineIcon />} />}
  />
  <IconButton
    aria-label="Toggled"
    toggled
    icon={<Icon glyph={<StarOutlineIcon />} />}
  />
  <IconButton
    aria-label="Disabled"
    disabled
    icon={<Icon glyph={<StarOutlineIcon />} />}
  />
  <IconButton
    aria-label="Loading"
    loading
    icon={<Icon glyph={<StarOutlineIcon />} />}
  />
</div>

**Focus** uses the same double ring as [Button](/components/button) — a gap
the colour of the surface, then a coloured outer ring. Other compact
controls (Chip dismiss, App Bar items, icon-only actions) should follow
that ring rather than inventing a separate overlay.

**Toggled** uses the active button colour to communicate "on" — pin a
message, favourite a channel, expand a panel. Pair the toggled state with
an `aria-pressed` attribute (the component sets this for you).

**Loading** replaces the icon with a Spinner and disables the button.
Use it when the action triggers async work and the result isn't immediate.

## Variants

### Rounded

A pill-shaped Icon Button. Use for action chips inside floating UI
(suggestions, hover trays) where the rounded shape signals
non-destructiveness.

  style={{
    display: 'flex',
    alignItems: 'center',
    gap: '0.75rem',
    padding: '1.5rem',
    background: 'rgba(0,0,0,0.04)',
    borderRadius: '8px',
  }}
>
  <IconButton
    aria-label="Rounded"
    rounded
    icon={<Icon glyph={<GlobeIcon />} />}
  />
</div>

### Destructive

For irreversible actions like deleting a message or removing a member.
Renders the icon in `--color-danger` and tints the hover background.

<div
  style={{
    display: 'flex',
    alignItems: 'center',
    gap: '0.75rem',
    padding: '1.5rem',
    background: 'rgba(0,0,0,0.04)',
    borderRadius: '8px',
  }}
>
  <IconButton
    aria-label="Delete"
    destructive
    icon={<Icon glyph={<TrashCanOutlineIcon />} />}
  />
</div>

### Tone

`tone` fills the button red (`danger`), green (`success`), yellow (`warning`) or
blue (`info`) with a white icon (dark on yellow, where white fails contrast), for a primary action that needs more weight than a
neutral Icon Button, such as Leave call. It differs from `destructive`,
which keeps the button transparent and colors only the icon.

<div
  style={{
    display: 'flex',
    alignItems: 'center',
    gap: '0.75rem',
    padding: '1.5rem',
    background: 'rgba(0,0,0,0.04)',
    borderRadius: '8px',
  }}
>
  <IconButton
    aria-label="Danger"
    tone="danger"
    icon={<Icon glyph={<TrashCanOutlineIcon />} />}
  />
  <IconButton
    aria-label="Success"
    tone="success"
    icon={<Icon glyph={<StarOutlineIcon />} />}
  />
  <IconButton
    aria-label="Warning"
    tone="warning"
    icon={<Icon glyph={<CloseIcon />} />}
  />
  <IconButton
    aria-label="Info"
    tone="info"
    icon={<Icon glyph={<GlobeIcon />} />}
  />
</div>

A host can retheme a tone with `--icon-button-tone-bg`, `--icon-button-tone-fg`,
`--icon-button-tone-hover-bg` and `--icon-button-tone-active-bg`.

### Inverted

For dark surfaces — sidebar, theme-coloured headers, banner overlays —
where the default colours wouldn't hold contrast. A dark surface that is not
the sidebar, such as the call window, supplies its own foreground and surface
colours; see Implementation.

<div
  style={{
    display: 'flex',
    alignItems: 'center',
    gap: '0.75rem',
    padding: '1.5rem',
    background: 'var(--sidebar-bg, #1E325C)',
    borderRadius: '8px',
  }}
>
  <IconButton
    aria-label="Inverted"
    appearance="inverted"
    icon={<Icon glyph={<CloseIcon />} />}
  />
  <IconButton
    aria-label="Inverted toggled"
    appearance="inverted"
    toggled
    icon={<Icon glyph={<StarOutlineIcon />} />}
  />
</div>

### Count

When a numeric badge belongs alongside the icon (notification counts,
unread totals), pass a `count` and the button switches from a fixed square
to an auto-width row. Numbers above 99 follow the Mention Badge convention
(`99+`).

## Tooltips & accessibility

- **Always provide an `aria-label`.** Icon Buttons have no visible text;
  the label is what screen readers announce.
- **Pair with a Tooltip.** A 400ms hover-delay Tooltip should appear on
  every Icon Button, repeating the `aria-label` text. Tooltips surface
  the action without forcing users to guess from the glyph.
- **Don't echo a visible label in a Tooltip.** Tooltips are for
  unlabeled controls, not redundant repeats.

<Divider />

## When to use

- **Icon Button that renders a link** — icon-only navigation, such as a
  header control that opens Settings. Pass `asChild` with an empty `<a>` or
  router `Link` child, and always provide an accessible name
  (`aria-label`). Toggle state (`toggled` / `aria-pressed`) is not available
  on links — use a plain Icon Button for on/off controls.
- **Plain Icon Button** — actions that change state, open menus, or dismiss
  surfaces without navigating.

<Divider />

## Implementation

Pass `icon={<Icon glyph={<SomeIcon />} />}` — never a raw compass-icons
glyph, and omit `size` so Icon Button can size via context.

Pass `asChild` with a single empty `<a>` or router `Link` child to render a
navigational icon control:

```tsx
import { IconButton } from '@mattermost/compass-ui/components/icon-button';
import { Icon } from '@mattermost/compass-ui/components/icon';
import CogOutlineIcon from '@mattermost/compass-icons/components/cog-outline';
import { Link } from 'react-router-dom';

<IconButton
  asChild
  aria-label="Open settings"
  icon={<Icon glyph={<CogOutlineIcon />} />}
>
  <Link to="/settings" />
</IconButton>;
```

The inverted style takes its colours from the sidebar theme by default. On a
dark surface that uses different colours, set the foreground and surface on
an ancestor and every inverted Icon Button below it follows. Without them the
sidebar colours apply, so existing uses do not change:

```scss
.call-surface {
  background: var(--calls-bg);
  --inverted-color: var(--calls-color);
  --inverted-color-rgb: var(--calls-color-rgb);
  --inverted-surface: var(--calls-bg);
}
```

In prototypes and layout specimens, wrap Icon Buttons with
`WithTooltip` from `@mattermost/compass-proto` for now so hover delay and
placement stay out of the button itself. The product uses the webapp
`WithTooltip` around the same `IconButton`.

For props, variants, and copy-ready examples, see the
[Icon Button specimen page](/components/icon-button/specimen).
