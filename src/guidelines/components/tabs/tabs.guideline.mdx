Tabs let people switch between sibling views inside the same surface — Mentions
in the right sidebar, sections of a settings panel, or filters on a list. The
content area changes; the surrounding chrome doesn't.

<Divider />

## Anatomy

A tab strip is a row of tab triggers, each with a label and optional badge,
and an optional controls slot for actions that apply to the whole strip
(filters, sorts, refresh).

<AnatomyStage>
  <Tabs
    tabs={[
      { key: 'all', label: 'All' },
      { key: 'unreads', label: 'Unreads', countBadge: 4 },
      { key: 'mentions', label: 'Mentions', unreadBadge: true },
    ]}
    activeKey="all"
    onChange={() => {}}
  />
</AnatomyStage>

- <Num>1</Num> **Tab list** — the row of triggers that switch the active view.
- <Num>2</Num> **Tab label** — the action text. Sentence case, short.
- <Num>3</Num> **Count badge** — optional numeric indicator for the active or
  total items in the tab.
- <Num>4</Num> **Unread dot** — optional unread indicator on inactive tabs;
  hidden when the tab becomes active.
- <Num>5</Num> **Controls slot** — optional trailing area for tab-strip-level
  actions.

## Behavior

Selecting a tab swaps the panel below; surrounding chrome stays put. The
active tab is highlighted with a tinted background and an accent-colored
label. Inactive tabs read as quiet
controls until hovered.

export const TabsDemo = () => {
  const [active, setActive] = useState('all');
  return (
    <Tabs
      tabs={[
        { key: 'all', label: 'All' },
        { key: 'unreads', label: 'Unreads', countBadge: 4 },
        { key: 'mentions', label: 'Mentions', unreadBadge: true },
      ]}
      activeKey={active}
      onChange={setActive}
    />
  );
};

<TabsDemo />

- **Count badge** — use when the number of items in a tab is meaningful at a
  glance (e.g. unread count, filter result size). Prefer a count over a dot
  when the user benefits from knowing how many.
- **Unread dot** — use when "something is new" matters but the count doesn't.
  The dot disappears once the tab is active to avoid implying "still
  unread."
- **Disabled** — keeps a tab visible when its view isn't available yet. The
  label dims, clicks do nothing, and arrow keys skip over it. Add a short
  native tooltip explaining what unlocks it.

## Appearance

Tabs come in two styles. The default highlights the active tab with a tinted
background. The underlined style draws a thin rule under the whole strip with
an accent indicator beneath the active tab — a lighter treatment for page-level
or panel-level navigation.

## Content

- Keep labels to one or two words. Sentence case.
- Tabs are siblings — labels should read as a parallel set ("All / Unreads /
  Mentions", not "All things / New / @ me").
- Don't pair tabs with a heading that says the same thing; the active tab is
  already the heading.
- If your strip needs more than five or six tabs, switch to a different
  navigation pattern (sidebar nav, dropdown filter).
