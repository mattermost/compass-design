The Draft List Item is one entry in the Drafts and Scheduled views. It shows
where a message is headed, a preview of it, and when it was last edited or will
send, with quick actions to edit, send, or delete it.

<Divider />

## States

| Status    | Use when                                                                    |
| --------- | --------------------------------------------------------------------------- |
| Draft     | An unsent message. The timestamp says when it was last edited.              |
| Scheduled | Will send at a set time. A Scheduled tag and the send time are shown.       |
| Failed    | A scheduled message that could not send. A danger tag and reason are shown. |

## Behavior

- Clicking the row (or pressing **Enter** / **Space** on it) opens the message
  for editing via `onClick`.
- Edit, Send, and Delete buttons render only when `onEdit`, `onSend`, or
  `onDelete` is passed. They are siblings of the row button and reveal on hover
  or `:focus-within` via opacity, so they stay in the tab order.
- The timestamp is hidden while the actions are revealed.
- Button names come from `editLabel`, `deleteLabel`, and `sendLabel`.

<Divider />

## Content

- Preview text is clamped to two lines.
- Keep destinations short: a channel name or a person's name.
