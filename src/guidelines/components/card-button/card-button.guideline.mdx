Card Buttons present a discrete choice as a compact card — leading icon,
title, optional description, and a check when selected. Use them when a
radio or segmented control would undersell the option (visibility, access
mode, plan tier).

Import from `@mattermost/compass-ui/components/card-button`.

<Divider />

## Usage

- Prefer a `CardButtonGroup` with `role="radiogroup"` and each card
  `role="radio"` for mutually exclusive choices.
- Keep titles short; put detail in the description line.
- Pass the leading glyph through `Icon` at size `24`.
- Selected state tints the icon well and border with `--button-bg` and shows
  a trailing check — do not add a second custom check.

Appropriate use cases:

- Private vs public / shared visibility.
- Access modes (invite-only vs open).
- Choosing between a small set of equally weighted options in a form or
  modal.

Avoid Card Buttons for multi-select filters — use Checkbox or Chip instead.
