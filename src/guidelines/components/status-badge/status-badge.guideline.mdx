A Status Badge tells you whether someone is reachable. It pairs with an
avatar or username so a glance is enough to know if a teammate is online,
focused, away, or signed out.

Status Badges are about presence, not activity. Don't repurpose them to
signal task state, build state, or anything else that isn't a person's
reachability.

<Divider />

## Anatomy

A single coloured glyph, scaled to sit on the corner of an avatar or inline
beside a name.

<AnatomyStage style={{ gap: '1rem', flexWrap: 'wrap' }}>
  <StatusBadge status="online" size="medium" />
</AnatomyStage>

The glyph carries the meaning — colour is reinforcement. Each status uses a
distinct shape so the badge stays legible in greyscale and to colour-blind
users.

## Statuses

| Status         | Glyph        | Meaning                                                      |
| -------------- | ------------ | ------------------------------------------------------------ |
| Online         | Filled check | Active and reachable.                                        |
| Away           | Clock        | Idle for the away threshold or set themselves Away manually. |
| Do Not Disturb | Minus circle | Notifications muted; reach out only if it's urgent.          |
| Offline        | Empty circle | Not signed in.                                               |

| Badge size | Avatar size | Use when                              |
| ---------- | ----------- | ------------------------------------- |
| XX-Small   | 20–24px     | Channel sidebar, dense lists.         |
| X-Small    | 28–32px     | The default for most surfaces.        |
| Small      | 40px        | Mention lists, compact cards.         |
| Medium     | 48–56px     | Profile popover header, member lists. |
| Large      | 128px       | Profile pages and large cards.        |

## On a colored surface

The badge defaults to the center channel surface. On the sidebar, global
header, or any other colored surface, set two CSS variables on the row or
container and nothing else:

| Variable                       | Controls                                | Default                                      |
| ------------------------------ | --------------------------------------- | -------------------------------------------- |
| `--status-badge-bg`            | Circle behind the glyph (all statuses). | `var(--center-channel-bg)`                   |
| `--status-badge-offline-color` | Offline glyph color.                    | `rgba(var(--center-channel-color-rgb), .32)` |

```css
.sidebar-row {
  --status-badge-bg: var(--sidebar-bg);
  --status-badge-offline-color: rgba(var(--sidebar-text-rgb), 0.32);
}
```

Online, away, and do not disturb use the theme-wide indicator colors, so they
need no override. Update `--status-badge-bg` per row state (hover, active,
selected) so the circle follows the row.
