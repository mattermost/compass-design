import { ChannelBookmarksBar } from '@mattermost/compass-proto';

`ChannelBookmarksBar` and `ChannelBookmarkModal` live in `@mattermost/compass-proto` for prototyping until a published API is ready.

The Channel Bookmarks Bar is a single row of quick links that sits directly
under the Channel Header. It lets members keep the links and files a channel
depends on one click away without pinning or searching.

- <Num>1</Num> **Bookmark** — Emoji (or a link / file icon when none is set) and
  name. Link bookmarks open in a new tab.
- <Num>2</Num> **Bookmark actions** — A small `•••` button that appears on hover
  or keyboard focus. Offers Edit, Copy link, and Delete. Hovering it keeps the
  bookmark's hover state.
- <Num>3</Num> **Add button** — A plus button inline after the last bookmark.
  Opens a menu to add a link or attach a file. Hidden for members who can't
  manage bookmarks.
- <Num>4</Num> **Overflow button** — When some bookmarks don't fit, the add
  button and the overflow control become one: a plus button with the number of
  hidden bookmarks beside it. Its menu lists the hidden bookmarks in order, then
  a divider, then the add options. For members who can't manage bookmarks it
  shows a more icon with the count and lists only the hidden bookmarks.

## Empty state

With no bookmarks, the plus button is replaced by an **Add bookmark** chip on
the left of the bar. It opens the same add menu. Members who can't manage
bookmarks see no bar at all.

## Overflow

The bar never wraps or scrolls. Bookmarks are shown in order, followed by the
plus button; when the next bookmark would not fit, the rest collapse and the
plus button becomes the combined overflow button (a plus with the hidden count,
for example `+ 2`), so there is never a separate overflow button beside it. The
split recalculates when the channel column is resized or bookmarks change, so
narrowing the window moves bookmarks into the menu one at a time.

## Add and edit

The plus button opens a menu with **Add a link** and **Attach a file**. The
choice decides the modal:

- **Link** — a link field and a title. An empty title defaults to the link's
  host; a missing or invalid link shows an inline error and keeps the modal
  open.
- **Attachment** — a file picker and a title. An empty title defaults to the
  file name; submitting without a file shows an error.

Both include an emoji button beside the title that opens the emoji picker; the
chosen emoji replaces the default icon in the bar, and can be removed again.
Editing reuses the modal for the bookmark's type with its values filled in and
a Save button.

## Reordering

Members who can manage bookmarks can reorder the bookmarks shown in the bar.
Drag a bookmark onto another: a bar marks where it will land and the dragged
bookmark dims. From the keyboard, focus a bookmark and press Alt with the
Left or Right Arrow key to move it one place; the move is announced to screen
readers and focus stays on the bookmark. Bookmarks in the overflow menu can't
be dragged, so move one into view by reordering the others, and reordering by
touch is left to the mobile version.

## Show or hide the bar

The channel header menu has a **Bookmarks bar** row that shows or hides the bar
for the channel. It is a checkable row: a check means the bar is shown. Hiding
the bar doesn't remove any bookmarks.

## Permissions

Members without permission to manage bookmarks still see the bar, open
bookmarks, and copy links. Add, Edit, and Delete are removed for them.

## Behavior

- Opening one menu closes any other. Escape and clicking outside close it, and focus moves into the menu on open and back to its trigger on close.
- Long names truncate with an ellipsis; the full name remains the accessible
  name.
- The bar is a toolbar with a translatable label, and every visible string can
  be overridden through `labels`.

## Implementation

See the Specimen tab for the interactive bar and modal. The host owns the
bookmark data and the modal's open state: pass `bookmarks` plus `onAdd`,
`onEdit`, `onCopyLink`, and `onDelete`, and render `ChannelBookmarkModal`
beside it with the `type` that `onAdd` reported.

```tsx
import {
  ChannelBookmarkModal,
  ChannelBookmarksBar,
} from '@mattermost/compass-proto';

<ChannelBookmarksBar
  bookmarks={bookmarks}
  onAdd={(type) => openModal(type)}
  onEdit={openEditor}
  onDelete={removeBookmark}
  onCopyLink={copyLink}
/>
<ChannelBookmarkModal
  open={modalOpen}
  type={addType}
  onClose={() => setModalOpen(false)}
  onSubmit={saveBookmark}
/>
```
