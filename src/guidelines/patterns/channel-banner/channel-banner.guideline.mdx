The Channel Banner is an unpublished prototyping composite in
`@mattermost/compass-proto`. It is the slim strip a channel admin sets across
the top of a channel: a notice, a classification, a reminder about where
escalations go. It sits above the messages and stays put while they scroll.

Use it for one short line that everyone in the channel should see. Use the
channel header for the channel's description and the Channel Info panel for
longer text.

## Anatomy

<AnatomyStage>
  <TokenBanner token="--color-blue-500">
    Triage within 15 mins. Escalations and discussions in ~threat-discussions
  </TokenBanner>
</AnatomyStage>

- <Num>1</Num> **Strip** — A slim, full-width bar in the color the admin chose.
- <Num>2</Num> **Text** — One centered line. Links inside it are underlined.

The text turns white or black on its own, so any color an admin picks stays
legible. White is preferred, and black takes over only on light colors where
white would be hard to read.

<Divider />

## States

- **Default** — The text fits on one line, centered in the strip.
- **Light and dark backgrounds** — White text on dark and vivid colors, black text
  on light ones such as yellow or pale teal.
- **Overflowing** — Text that does not fit ends in an ellipsis. Hovering the strip
  shows the full text in a tooltip.
- **Empty** — With no text there is no banner at all, not an empty colored strip.

<Divider />

## Behavior

The banner is one line by design. Keep the message short, and put the detail in a
link rather than a longer sentence.

The text is a prop, so a host can render Markdown or translated copy into it.
The tooltip text is a prop too, and the text can take an optional accessible
name (`textAriaLabel`); without one, screen readers read the banner copy.
