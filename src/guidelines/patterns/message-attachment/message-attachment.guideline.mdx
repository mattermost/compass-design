The Message Attachment is an unpublished prototyping composite in
`@mattermost/compass-proto`. It is the card an integration posts under a
message: an alert from a monitoring tool, a build result, a ticket update. A
colored bar on the left edge sets the tone, and the card can carry a title,
text, a grid of fields, an image, action buttons, and a footer.

Use it for structured, glanceable status from an integration. Use plain message
text for conversation, and the Attachment Card for a shared file.

## Anatomy

<AnatomyStage>
  <MessageAttachment
    color="warning"
    title="Multiple failed login attempts"
    text="Five failed sign-ins for the same account within two minutes."
    fields={[
      { title: 'Node', value: 'admin panel', short: true },
      { title: 'Severity', value: 'Medium', short: true },
    ]}
    actions={[{ label: 'View alert', href: 'https://example.com' }]}
    footer="Security Alerts"
    thumbSrc={thumbnail}
  />
</AnatomyStage>

- <Num>1</Num> **Color bar** — A 3px bar on the left edge. Green, yellow, red
  and blue are the semantic colors for good, warning, danger and info; any CSS
  color also works. Without a color the bar is neutral.
- <Num>2</Num> **Title** — The headline. It can link out.
- <Num>3</Num> **Text** — Supporting detail.
- <Num>4</Num> **Fields** — Label and value pairs. Short fields sit two to a
  row; the others take a full row. Fields keep their order.
- <Num>5</Num> **Actions** — Buttons for what to do next. A button with a link
  opens it in a new tab.
- <Num>6</Num> **Thumbnail** — Optional. A square image in its own column on the
  right, beside the title, text, fields, actions and footer. It is cropped to
  fill its box and has softly rounded corners.
- <Num>7</Num> **Footer** — Optional. Where the alert came from, with an
  optional icon. Leave it out when the author or integration name above the post
  already says so.

An optional line of text, the pretext, sits above the card. A wide image can sit
under the fields.

## States

- **Default** — The card sits on the channel background with a thin outline.
- **Color** — Good, warning, danger, info, a custom color, or neutral.
- **With a thumbnail** — The image takes its own column on the right and the
  content fills the rest.
- **Narrow** — Below roughly 440px of its own width the short fields stack
  into one column, and the thumbnail moves below the content. It follows its
  container, not the viewport, so it also stacks in a thread panel.

Every part is optional. A card with only a title and text is valid, and empty
parts are left out.

<Divider />

## Behavior

The card is presentational. Pass the same values the integration sent: the
props mirror the Mattermost and Slack attachment format, so a host can map a
post's attachments straight onto them. The host decides what each action does.

Field and text values render as plain text. Format them before you pass them in; the card does not interpret Markdown.

Never rely on color alone to carry severity. Put the severity in the title or a
field as well, so it reads without color.
