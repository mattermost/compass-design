The Quick Switch Modal ("Find channels") is the keyboard-first way to jump to a channel, direct
message, or group message. Users open it with a shortcut, type a few letters,
and press Enter. It lives in `@mattermost/compass-proto` as a prototyping
surface and is not yet published to `@mattermost/compass-ui`.

- <Num>1</Num> **Header** — the "Find channels" title and a close button.
- <Num>2</Num> **Search field** — a medium search input under the title. It
  keeps focus the whole time; the arrow keys move the highlight without leaving
  it.
- <Num>3</Num> **Results** — menu items with a channel glyph, the name, and a
  muted handle after it. The highlighted row has a soft fill.
- <Num>4</Num> **Group headings** — small all-caps labels such as Unread and
  Recent that title consecutive results.

<Divider />

## States

- **Default** — every destination in the host's order, grouped (for example
  Unread, then Recent), with the first row highlighted.
- **Filtered** — rows narrow as the user types. Every word must match the name,
  handle, or a keyword. Headings appear only above groups that still have
  results, and the highlight returns to the first row.
- **Empty** — a centered "No results found" message replaces the list.

## Keyboard

| Key        | Action                                   |
| ---------- | ---------------------------------------- |
| Down / Up  | Move the highlight, wrapping at the ends |
| Home / End | Jump to the first or last result         |
| Enter      | Open the highlighted result              |
| Escape     | Close and return focus to where it was   |

<Divider />

## Implementation

The host owns open state, the shortcut that toggles it, and what selecting a
row does. Pass `items` and `onSelect`; call `onClose` from `onSelect` to
dismiss. See the Specimen tab for a live example.

```tsx
import { QuickSwitchModal } from '@mattermost/compass-proto';

<QuickSwitchModal
  open={open}
  onClose={() => setOpen(false)}
  items={channels}
  onSelect={(item) => {
    navigate(item.id);
    setOpen(false);
  }}
/>;
```
