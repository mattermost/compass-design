Right Sidebar Search Results is one recipe for every list of messages the right
sidebar shows: search results, recent mentions, saved messages and pinned
messages. Each result names where the message lives, shows the message with the
search terms highlighted, and offers a Jump link to open it in context. It lives
in `@mattermost/compass-proto` as a prototyping surface and is not yet published
to `@mattermost/compass-ui`.

- <Num>1</Num> **Count** — how many results the list holds ("3 results"). It is
  announced to screen readers when the list changes.
- <Num>2</Num> **Context line** — the channel (or direct message) in bold, then
  the team in a muted tone. The Jump link sits at the end of the line.
- <Num>3</Num> **Message** — the usual message layout (avatar, name, time, body)
  without the hover toolbar. A Pinned and Saved row appears above it when the
  message is pinned or saved.
- <Num>4</Num> **Highlight** — every match of a search term in the body gets a
  yellow mark. Mentions, saved and pinned lists pass no terms, so nothing is
  marked.

<Divider />

## States

- **Results** — one row per result, separated by hairlines, newest first.
- **Jump** — hidden until the row is hovered or focused, and always reachable by
  keyboard. Pressing it opens the message in its channel.
- **Empty** — a centered illustration, title and one-line hint replace the list.
  The copy depends on the list: no results, no mentions, nothing saved, nothing
  pinned.

<Divider />

## Implementation

Compose the body inside `RightSidebar` with a `RightSidebarHeader` whose title
matches the list. The host owns fetching, ordering and what Jump does. See the
Specimen tab for a live example.

```tsx
import {
  RightSidebar,
  RightSidebarSearchResults,
} from '@mattermost/compass-proto';
import { RightSidebarHeader } from '@mattermost/compass-ui/components/right-sidebar-header';

<RightSidebar
  header={<RightSidebarHeader title="Search results" onClose={close} />}
>
  <RightSidebarSearchResults
    results={results}
    terms={['sidebar']}
    onJump={(result) => navigateToPost(result.id)}
  />
</RightSidebar>;
```
