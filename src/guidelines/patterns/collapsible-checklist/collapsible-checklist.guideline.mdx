import { CollapsibleChecklist } from '@mattermost/compass-proto';

The Collapsible Checklist is an unpublished prototyping composite in
`@mattermost/compass-proto`. It is a named Playbooks checklist section: a
header that collapses, a title, “n / n done”, a progress bar, task rows, and
“Add a task”.

Use it in a run RHS, a channel checklist, or a playbook editor prototype. It
composes [`ChecklistItem`](/components/checklist-item) for each row.

- <Num>1</Num> **Header** — Chevron, section title, and “n / n done”. Click to
  collapse or expand.
- <Num>2</Num> **Progress** — A thin bar under the header for completed work.
- <Num>3</Num> **Task rows** — Each row is a `ChecklistItem`, including its
  hover actions toolbar (assign, due date, edit, more).
- <Num>4</Num> **Add a task** — Opens an inline edit row to create a task.
- <Num>5</Num> **Section menu** — Optional rename, duplicate, and delete actions
  on hover (portaled menu).

Skipped tasks are left out of the done count. Requirements, condition headers,
and bulk select stay out of this first cut.

## Behavior

Collapse keeps the body mounted and animates with the same CSS grid
`0fr`↔`1fr` pattern used by `AdminPanel`. There is no shared Accordion or
Disclosure primitive yet; hosts that need the same motion can copy that recipe
until one lands.

Checking a task and adding a task update through `items` / `onItemsChange`
(or uncontrolled `defaultItems`).
